Blindleia Darts Platform

Klubbportal, turneringsdrift og kiosk i samme løsning.

Testmiljøet er nå organisert som en lokal turneringsplattform med tydelig skille mellom medlem/portal, admin/backoffice, kiosk og skjerm.

Portal og Admin Klubbvalg, innlogging, turneringspåmelding, spilleroversikt, turneringsstyring og kioskoppsett. Kiosk V1 Board-side flyt for assigned matches, start av kamp, sum-input, undo og live scoreboard per kiosk. Venue Screen Live oversikt over kiosker, aktive turneringer og siste kamper for valgt klubb. API Intern API-first runtime for portal, kiosk, screen og senere connector-publishing.
