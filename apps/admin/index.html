Kom i gang

Bruk admin i denne rekkefølgen

1. Klargjør boards

Gå til Boards og kiosker og opprett eller juster kioskene som skal brukes i lokalet.

2. Pair nettbrett

Åpne kiosk på nettbrettet, start pairing fra tannhjulet og godkjenn forespørselen i admin.

3. Tildel kamp

Bruk Board Calls for å sende riktig kamp til riktig board under turneringskvelden.

Brukerveiledning

Slik bruker du løsningen i praksis

Før turnering

1. Velg klubb.

2. Opprett eller kontroller spillere.

3. Opprett eller kontroller turnering.

4. Opprett boards og legg inn sponsorlabel eller sponsorlogo.

Pairing av nettbrett

1. Åpne kioskflaten på nettbrettet.

2. Trykk tannhjulet og velg start pairing.

3. Gå til Boards og kiosker i admin.

4. Godkjenn pairing og velg hvilket board nettbrettet skal låses til.

Under turnering

1. Gå til Board Calls.

2. Tildel ventende kamper til ledige boards.

3. Spillerne går til riktig kiosk og starter kampen.

4. Screen kan brukes som publikumsvisning.

Hvis noe går galt

Bytt scoring-modus, nullstill pairing på kiosken, eller tildel kampen til et annet board.

Hvis et nettbrett byttes ut, pair det på nytt i stedet for å opprette nytt board.
