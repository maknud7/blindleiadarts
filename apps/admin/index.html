Arkitekturretning

Hvordan dette skal fungere

Challonge skal ikke eie board calls eller lokal runtime. Det skal være connector for bracket/import/publish.

Board-tildeling skjer lokalt i Blindleia Darts, basert på hvilke boards som er godkjent for turneringen.

Kiosk er alltid knyttet til klubb via boardet den tilhører, og pairing godkjennes av klubbadmin.

Klubbkode

Koble nettbrett til riktig klubb

Alle klubber bruker samme kiosk-URL. Nettbrettet taster derfor først inn en klubbkode, og først deretter kan det sende pairing request til boards i akkurat denne klubben.

Klubbkode for kiosk
---
Bruk denne koden på /kiosk/ før pairing startes.

Ny flyt

1. Åpne `/kiosk/` på nettbrettet.

2. Tast inn klubbkoden over.

3. Start pairing fra tannhjulet.

4. Godkjenn requesten under og velg board.

Tablet Pairing

Ventende nettbrett

Nettbrett ber om pairing fra kioskflaten. Godkjenn her og bind forespørselen til riktig board.

Flyt

1. Åpne kiosk på nettbrettet.

2. Trykk start pairing i tannhjulet.

3. Nettbrettet viser pairingkode og adminlenke.

4. Godkjenn forespørselen her og velg board.

Venue Screen

Skjermkoder for klubben

Alle klubber bruker samme screen-URL. En skjerm kobles til klubb ved å taste inn en kode én gang på oppstartsskjermen.

Ny skjermkode

Systemet lager en kort kode som kan tastes inn på /screen/ og som deretter huskes på enheten.

Brukerveiledning

Slik bruker du løsningen i praksis

Før turnering

1. Velg klubb.

2. Opprett eller kontroller spillere.

3. Opprett eller kontroller turnering.

4. Opprett boards og legg inn sponsorlabel eller sponsorlogo.

Pairing av nettbrett

1. Åpne kioskflaten på nettbrettet.

2. Tast inn klubbkoden som vises i admin.

3. Trykk tannhjulet og velg start pairing.

4. Gå til Boards og kiosker i admin og godkjenn pairing mot riktig board.

Under turnering

1. Gå til Board Calls.

2. Tildel ventende kamper til ledige boards.

3. Spillerne går til riktig kiosk og starter kampen.

4. Screen kan brukes som publikumsvisning.

Hvis noe går galt

Bytt scoring-modus, nullstill pairing på kiosken, eller tildel kampen til et annet board.

Hvis et nettbrett byttes ut, pair det på nytt i stedet for å opprette nytt board.
